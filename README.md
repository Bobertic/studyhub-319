# StudyHub — Учебный ресурс для группы 319

![GitHub License](https://img.shields.io/github/license/Bobertic/studyhub-319)

**StudyHub** представляет собой веб-ресурс, предназначенный для студентов группы 319, обеспечивающий удобный доступ к лекционным материалам, заданиям и дополнительным ресурсам.

---

## 📌 Описание

**StudyHub** разработан с целью упрощения доступа к учебным материалам. С его помощью студенты могут быстро находить:

- 📚 Лекции и учебные материалы
- 📝 Домашние задания и практические работы
- 📎 Дополнительные материалы для подготовки

Все материалы собраны в одном месте, что позволяет сократить время на поиск информации.

> **Важно:** В репозитории GitHub хранятся **минифицированные версии** всех файлов (HTML, CSS, JavaScript). Это сделано для оптимизации скорости загрузки и производительности сайта, особенно на слабых устройствах. Исходные не минифицированные файлы доступны в закрытом хранилище разработчика.

---

## 🚀 Использование

1. Перейдите по ссылке: <a href="https://bobertic.github.io/studyhub-319/" target="_blank">StudyHub</a>
2. Пользуйтесь навигацией по категориям и ссылкам для доступа к материалам

> Проект не требует установки сервера и функционирует через GitHub Pages.
